# Dave Sensei's classroom tools

Small, free tools for English lessons, made for a classroom projector and students' phones.
They run in the browser, need no sign-up, and are live at **https://davesensei.com**.

## The tools

- **Picker wheel**: spin a wheel to pick a student, a topic or a number. Paste names separated by commas or new lines.
- **Timer**: a countdown, or a repeating interval timer that beeps when it is time to swap.
- **Group maker**: split the class into pairs or groups. When the class does not divide evenly, choose a few
  smaller groups or a few bigger ones. Mark absent students for the day, and new rounds avoid putting the same
  partners together again.
- **Sound articulator**: an animated cross section of the head showing how each English consonant and vowel is
  made, including "tricky pairs" such as l/r, b/v and s/th that Japanese learners often find hard.
- **Bingo**: paste 9 to 100 words or phrases and get two links: one for the teacher (a wheel to call items) and one
  for students. Each student gets their own random board on their phone and taps to cross off squares.
  Students scan a QR code to join. Sessions end after 24 hours.

## Privacy

- No accounts, no ads, no tracking.
- The picker, timer, group maker and articulator keep everything in your own browser. A class list you save
  there stays on that device.
- Bingo stores your word list on the server for 24 hours so students' phones can load it, then deletes it.
  It never asks for student names.

## Using the tools in your own classes

Just open https://davesensei.com. Each tool is a single HTML page in the `site/` folder, so you can also read
how it works or adapt it.
